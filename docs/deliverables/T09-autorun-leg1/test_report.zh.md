## 1. 声称的结论

`src/freight_lineitems/` 的主线（读入、脱敏、数字切分、盲解析的 agent 循环、提交检查、三档规则、两层查重、SQLite 和两种导出）用真实模型（`claude-sonnet-5-5`，思考关闭）跑通：开发集样本 273 条（不同记录）、公开 mock 375 行，每条都经过模型，强制检查全部通过，没有静默失败。这**不是**浅绿的声称：没有跑开发集全量，门槛也没有事先写定。

## 2. 为什么是这个证据级别

样本 A、B2 来自开发集，开发 SKILL.md 和规则时看过开发集的写法；措辞调优只看 A，B（审计后换为 B2）和 mock 用来验证，但 mock 的写法我们在确定性核对时也看过。所以全部算"样本内"。

## 3. 检验方法

- pytest：69 个测试（其中 2 个读测试集 ID 的默认跳过）。
- 88 个 Codex 边界用例逐条核对（`docs/autorun/boundary_cases_review.zh.md`）。
- 公开 mock 确定性层核对（`docs/autorun/mock_deterministic_review.zh.md`）。
- 真实模型运行：样本 A、B2 各 100 条，公开 mock 375 行，A 的前 50 条重复 3 次。
