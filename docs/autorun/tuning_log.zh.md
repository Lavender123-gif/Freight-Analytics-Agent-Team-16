规则（任务书阶段 3 第 5 条）：只看样本 A 上的失败来改 SKILL.md 或工具说明；改完在 B 和公开 mock 上验证；最多三轮；某一轮在 B 或 mock 上变差就回退这一轮。只写通用的阅读约定，不针对某条记录或某个承运商（用户 11-10 要求 d）。

**"变差"的判定（跑之前写定）**：以下任一成立即视为变差，回退该轮：
1. mock：最终主张金额正确的事件数比上一轮少 3 个以上（360 个事件，约 1 个百分点）；
2. mock：首次就正确的事件数比上一轮少 3 个以上；
3. B：首次不一致的条数比上一轮多 2 条以上（100 条）；
4. B：`CLAIM.RECON.TOTAL_MISMATCH` 或 `RUN.AGENT.UNCERTAINTY_REPORTED` 的条数比上一轮多 3 条以上；
5. 任一集上出现强制检查最终不通过（`FAILED_CHECKS`）或没有提交的记录，而上一轮没有。
差异在上述幅度以内视为持平，保留该轮改动（它针对的是 A 上看得见的错误）。
