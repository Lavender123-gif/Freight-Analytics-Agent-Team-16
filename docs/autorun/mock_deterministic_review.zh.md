## 不符的分三类

**一、我们的 bug（已修，有测试或在本表复核）**

| 问题 | 例子（合成） | 修法 |
|---|---|---|
| 逗号千分位被拆成两个数 | `$1,234.50` → `$1` 和 `234.50` | 数字切分接受 `1,234.50`；开发集没有这种写法，切分结果不变 |
| 电话没有脱敏，还会被当成数字 | `202-555-0101`、`(212) 555-0102` | 加电话脱敏 `[PHONE_n]`；"脱敏改动了数字"检查同样排除电话 |
| 拼写出来的邮箱没有脱敏 | `name dot x at domain dot invalid`、`[AT]`、`(at)` | 加拼写邮箱脱敏 |
| 费用名被当成人名脱敏 | 对照组 `LIFTGATE`；开发集上 `TONU`、`DELV` 也被误脱敏 | 只由代码表词汇组成的片段不再当人名（开发集上只去掉了这几处误脱敏，没有漏掉真名） |
| 注入检查漏掉通用写法 | `IGNORE ALL RULES`、`SYSTEM:`、`DISREGARD PRIOR INSTRUCTIONS`、`ADMIN NOTICE`、拆字母 `i G n O r E rU1es`、西里尔字母 `І` | 加三组通用模式和一份只用于匹配的规范化副本；开发集上注入命中仍为 0 |
