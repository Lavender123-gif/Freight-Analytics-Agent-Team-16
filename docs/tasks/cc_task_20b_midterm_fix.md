现状：审核页面按发票列出说明，表头的合计是页面自己把各条说明的读数相加，表头的建议取各条说明里最差的一个，没有读取票货汇总的结果。同一票货有取代时，页面显示"解析通过"和相加的总额，票货输出却是"人工审核"和按取代规则算的默认总额。页面文字是中文，PPG 的审核员读不了。

3. 页面上所有给人看的文字改成英文：建议、严重程度、按钮、表头字段、提示语。
