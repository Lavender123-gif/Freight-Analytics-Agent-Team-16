# 任务 23c：贷记"本地范围"的边界只按像金额的数字划分

日期：2026-11-16。接任务 23b。规则不变，只改本地范围的边界定义。

## 0. 总则

在分支 `mvp-v1` 上继续，单独提交，提交信息带任务编号。不推送，不调模型，不改系统提示词和 skill 文字，不碰测试集和预留 mock。截止今天 12:15。

## 1. 为什么改

23b 用数字表里的**所有**数字划分本地范围，编号、数量也算边界。这样 `CREDIT MEMO 12345 $50.00` 里，贷记词和 50 之间隔着 12345，贷记词就不算 50 的依据：模型把 50 读成正数时不会送人工，正负号可能静默读错。

## 2. 改法

- 本地范围的边界只取**由代码判定像金额的数字**：带 `$`，或恰好两位小数。判定只看数字表，不看模型的读法，模型仍然改不了边界。编号、数量、重量、日期不再切断范围。
- 规则 1、规则 2 和紧贴负号的规则都不变，只是改用新的本地范围。

## 3. 测试和重放

1. 新测试：`CREDIT MEMO 12345 $50.00` 读成正数 → 送人工；读成贷记 → 通过。`CREDIT $10.00 WAS PAID; LIFTGATE $50.00` 把 50 读成贷记 → 仍然拒绝。23b 的测试全部照旧通过。
2. 在三份存档读法上重放，和 23b 的数字对比，变化的逐条列出。开发集新增送人工超过 3 条就停下找我。
