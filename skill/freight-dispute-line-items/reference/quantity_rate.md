# Topic note: quantity x rate

Code added this note because the text has a unit price or a count (`@`, PER, EACH, DAYS, HOURS, '2 X $50').

- {{CONCEPT:quantity_rate}}
- A unit price written with `$` that you do not count needs an exclusion phrase such as `EACH`, `PER DAY` or `@`.
- Free time, dates and hours of arrival and departure are not money: `QUANTITY` or `REFERENCE` with status `NONE`.
